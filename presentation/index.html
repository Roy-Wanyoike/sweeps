02 ZOD-VALIDATED OUTPUTS

Every LLM output is schema-checked. One retry with the validation error appended — then a deterministic fallback template takes over. The pipeline never dead-ends on a bad generation.

LLM → ZOD ✓ → COMMIT ZOD ✗ → RETRY ×1 STILL ✗ → FALLBACK TEMPLATE
